# Kosmos Prompts

Reusable system prompts that pair with the four Perplexity Computer skills under `../skills/`.

- `kosmos-build-system-prompt.md` — attach for any build session. Enforces the non-negotiables and session ritual.
- `kosmos-debug-system-prompt.md` — attach for any debug session. Enforces the search-DEBUG_LOG-first rule.

Load the corresponding skill (`kosmos-port-workflow`, `kosmos-adr-authoring`, `kosmos-log-maintenance`, `kosmos-spec-diff`) as the situation demands. The prompts assume those skills are available.
